# 1997–2097 — Public Field Note

## Local development

```bash
npm install
npm run dev
```

Production build and checks:

```bash
npm test
npm run lint
```

## Archive structure

- `TIME` — 時間から読む
- `PLACE` — 場所から読む
- `SEQUENCE` — 記録の連なりから読む
- `OBJECT` — 観察対象から読む

The site is a single-route vinext app designed to run on GitHub Pages or a compatible static/edge host.
